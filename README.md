# 🧠 Tech Heroes Memory Game
TryGame: [@TechHeroes](https://techheroesactivities.vercel.app/)
A fun and interactive memory card matching game developed as part of **Tech Heroes Academy** activities.

Challenge your memory, improve your concentration, and test your skills by finding matching card pairs while achieving the highest possible score!

## 🎮 Game Overview

Tech Heroes Memory Game is a browser-based game where players flip cards, find matching pairs, and complete the board with the best possible score.

The game offers multiple difficulty levels, real-time statistics, and a clean interactive interface.

## ✨ Features

- 🃏 **Card Matching:** Flip cards and find matching pairs.
- 🎯 **Multiple Difficulty Levels:** Choose between Easy, Medium, and Hard.
- ⏱️ **Game Timer:** Track the time spent completing the game.
- 🔢 **Move Counter:** Keep track of your attempts.
- ⭐ **Scoring System:** Earn points for every successful match.
- 🏆 **Best Score:** Automatically save your highest score using Local Storage.
- 📊 **Game Progress:** Monitor your matching progress.
- 🎉 **Win Screen:** Celebrate when all pairs are matched.
- 🔄 **Restart Game:** Start a new game whenever you want.
- 📱 **Responsive UI:** Enjoy a comfortable gaming experience across different screen sizes.

## 🎚️ Difficulty Levels

| Level | Number of Pairs | Total Cards |
|---|---:|---:|
| Easy | 4 | 8 |
| Medium | 8 | 16 |
| Hard | 12 | 24 |

## 🕹️ How to Play

1. Choose your preferred difficulty level.
2. Click on a card to reveal its content.
3. Select another card to find its matching pair.
4. Matching cards remain revealed.
5. Non-matching cards are flipped back automatically.
6. Continue until all pairs are matched.
7. Complete the game and try to beat your best score!

## 🛠️ Tech Stack

- **React 19** – Building interactive user interfaces.
- **JavaScript (ES6+)** – Game logic and functionality.
- **Vite** – Fast development environment and build tool.
- **CSS3** – Styling, layouts, and card animations.
- **React Hooks** – Managing application state and side effects.
- **Local Storage** – Persisting the best score.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Hazem-Alsaqaan/Tech_Heroes_Memory_Game.git
```

2. Navigate to the project directory:

```bash
cd Tech_Heroes_Memory_Game
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite in your browser.
